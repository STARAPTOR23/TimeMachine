# 1960s — manual banner

Drop a hand-picked banner image for the 1960s here (e.g. `banner.jpg` or `banner.png`).

This folder is separate from the main-UI card banners (`assets/images/card-events.gif`,
`card-movies.gif`, `card-culture.gif`, `card-facts.gif`), which stay exactly as they are —
nothing here changes or replaces those. This is just a place to keep manually-curated
per-decade artwork organized, ready to be wired in later.
